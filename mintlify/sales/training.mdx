## Overview

New sales reps complete **five practice appointments** in the Creativ app using the same full workflow as real jobs (survey → OpenSolar → calculator → contract → outcome).

- **Reps:** Profile → **My Training**
- **Admins:** Profile → **Training Management**

All five scenarios are available as soon as an admin starts a program.

## Tariff reference (100Green Smart Tide)

### Current electricity tariff

- Use the customer's latest bill if available
- If no bill is available, use **capped rate 25p/kWh**

**Calculate annual usage (no bill):**

Monthly direct debit × 12 ÷ 0.25 = Annual usage (kWh)

Example: £120 × 12 ÷ 0.25 = **5,760 kWh**

### New electricity tariff

**Single rate**

- Day rate: **27.73p/kWh**
- Night rate (7 hours): **7p/kWh**

**Dual rate**

- Day rate: **36.26p/kWh**
- Night rate (7 hours): **7p/kWh**

**Export:** **12p/kWh**

## How-to guides

### Find the property

1. Use [FindMyAddress](https://www.findmyaddress.co.uk/search) to look up and verify the scenario address.
2. In **OpenSolar**, locate the roof for that address. If the property is hard to see on the default map, **switch map imagery inside OpenSolar** (including **Bing Maps**) before asking the office for help.

**Property not visible on OpenSolar or Bing Maps?** After trying different map sources in OpenSolar, collect:

1. **Clear pictures of the target roof** — show the area where panels may be installed
2. **Picture of the cable to show the angle** — helps show pitch and direction
3. **Compass reading** — stand away from the property and target roof, then take a reading
4. **Pictures of shading issues** — trees, chimneys, nearby buildings, roof structures, or other obstructions
5. **Send everything in Teams** — photos and compass reading so the office can advise what to enter in OpenSolar

### Design on OpenSolar (before you start)

Create and save the OpenSolar design **before** you tap **Start appointment** in My Training. Follow the [OpenSolar design guide](https://support.opensolar.com/hc/en-us/articles/7576156328207--Design).

When you reach **Link OpenSolar Design** in the workflow, enter the **project ID** or **property address** to link the design you created — do not search for unrelated projects.

## Training mode and contract/payment steps

Training appointments use **fake customers**. Reps still run the real workflow screens.

If contract signing, DocuSeal, or payment steps block progress:

1. Rep continues as far as possible and notes where they are stuck
2. Admin opens **Profile → Training Management → program → Override** for that scenario
3. Admin uses **Workflow Override** to mark the blocked step complete
4. Rep resumes from **My Training → Start appointment**

### Admin override playbook

| Stuck step | Override action |
|------------|-----------------|
| Survey images | Workflow Override → fill placeholder images or mark survey complete |
| OpenSolar / Calculator | Mark step complete after verifying rep did the work |
| Contract / disclaimer / express consent | Mark step complete (no real signature for training customers) |
| Payment | Mark step complete — do not capture real payment |
| Outcome | Rep selects won/lost/quoted on step 13, or admin completes step 13 |

## For admins

1. **Start training:** Training Management → select rep → **Start Training**
2. **Monitor progress:** Open the program to see each scenario's workflow step
3. **Review:** Add admin notes per scenario when the rep finishes
4. **Cancel:** Active programs can be cancelled from the progress screen

Program completes automatically when all five scenarios record a workflow outcome.
