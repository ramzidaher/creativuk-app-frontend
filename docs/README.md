# Creativ Solar frontend docs

These docs live in the repo so they stay accurate as the code and deployment evolve.

## Start here

- `docs/ARCHITECTURE.md`: structure (routing, auth, API layer, theming)
- `docs/SETUP.md`: local development (Expo), common scripts, URL switching
- `docs/DEPLOYMENT-IIS-AZURE.md`: deploying the built SPA to Azure Windows Server + IIS
- `docs/WEB-CONFIG.md`: how `public/web.config` works (SPA fallback + `/api` proxy)
- `docs/API-URLS.md`: how the frontend decides `API_BASE_URL` (dev vs production)
- `docs/TROUBLESHOOTING.md`: common failures + what to check

## Adding new docs (recommended)

- Add “runbook” style pages for operational tasks (deploy, restart backend, rotate certs, etc.)
- Add feature flow docs for your most important user journeys (workflow + signing)
